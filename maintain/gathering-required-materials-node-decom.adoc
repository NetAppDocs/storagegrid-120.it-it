= Raccogliere il materiale necessario per il decommissionare del nodo StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di decommissionare un nodo della grid, devi ottenere le seguenti informazioni.

[cols="1a,2a"]
|===
| Articolo | Note 


 a| 
File del pacchetto di ripristino `.zip`
 a| 
Devi link:downloading-recovery-package.html["scarica il pacchetto di ripristino più recente"] `.zip` file (`sgws-recovery-package-_id-revision_.zip`). Puoi usare il file del pacchetto di ripristino per ripristinare il sistema se si verifica un errore.



 a| 
`Passwords.txt` file
 a| 
Questo file contiene le password necessarie per accedere ai nodi della griglia tramite riga di comando ed è incluso nel pacchetto di ripristino.



 a| 
Passphrase di provisioning
 a| 
La passphrase viene creata e documentata quando il sistema StorageGRID viene installato per la prima volta. La passphrase di provisioning non è presente nel file `Passwords.txt`.



 a| 
Descrizione della topologia del sistema StorageGRID prima del decommissioning
 a| 
Se disponibile, procurati qualsiasi documentazione che descrive la topologia attuale del sistema.

|===
