= Modificare la configurazione DNS per un singolo nodo StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Anziché configurare il DNS a livello globale per l'intera implementazione, puoi eseguire uno script per configurare il DNS in modo diverso per ciascun nodo della griglia.

In generale, dovresti usare l'opzione *Manutenzione* > *Rete* > *Server DNS* nel Grid Manager per configurare i server DNS. Usa il seguente script solo se hai bisogno di usare server DNS diversi per diversi nodi della griglia.

.Passaggi
. L'accesso SSH esterno è bloccato per impostazione predefinita. Se necessario, link:../admin/manage-external-ssh-access.html["Consenti temporaneamente l'accesso"].
. Accedi al nodo amministratore principale:
+
.. Inserisci il seguente comando: `ssh admin@_primary_Admin_Node_IP_`
.. Inserisci la password indicata nel file  `Passwords.txt`.
.. Inserisci il seguente comando per passare all'utente root: `su -`
.. Inserisci la password indicata nel file  `Passwords.txt`.
+
Quando sei connesso come root, il prompt cambia da  `$` a  `#`.

.. Aggiungi la chiave privata SSH all'agente SSH. Inserisci: `ssh-add`
.. Inserisci la password di accesso SSH indicata nel file  `Passwords.txt`.


. [[log_in_to_node]]Accedi al nodo che vuoi aggiornare con una configurazione DNS personalizzata: `ssh _node_IP_address_`
. Esegui lo script di configurazione DNS: `setup_resolv.rb.`
+
Lo script risponde con l'elenco dei comandi supportati.

+

. Aggiungi l'indirizzo IPv4 di un server che fornisce domain name service per la tua rete: `add <nameserver IP_address>`
. Ripeti il  `add nameserver` comando per aggiungere i name server.
. Segui le istruzioni che ti vengono richieste per gli altri comandi.
. Salva le modifiche ed esci dall'applicazione: `save`
. [[close_cmd_shell]]Chiudi la shell dei comandi sul server: `exit`
. Per ogni nodo della griglia, ripeti i passaggi da <<log_in_to_node,accedere al nodo>> a <<close_cmd_shell,chiudere la shell dei comandi>>.
. Quando non hai più bisogno dell'accesso senza password ad altri server, rimuovi la chiave privata dall'agente SSH. Inserisci: `ssh-add -D`
. Se hai consentito l'accesso SSH esterno, link:../admin/manage-external-ssh-access.html["blocco accesso"] quando hai finito di modificare la configurazione DNS.
