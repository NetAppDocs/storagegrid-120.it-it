= Modificare la password per l'utente root locale di un tenant StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Potresti dover cambiare la password dell'utente root locale di un tenant se l'utente root è stato bloccato dall'account.

.Prima di iniziare
* Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].
* Hai link:admin-group-permissions.html["autorizzazioni di accesso specifiche"].


.Informazioni su questa attività
Se il single sign-on (SSO) è abilitato per il tuo sistema StorageGRID, l'utente root locale non può accedere all'account tenant. Per eseguire le attività dell'utente root, gli utenti devono appartenere a un gruppo federato che dispone dell'autorizzazione di accesso Root per il tenant.

.Passaggi
. Seleziona *tenant*.
+
image:tenant_accounts_page.png["Pagina degli account tenant"]

. Seleziona il tenant account. Puoi fare una delle seguenti cose:
+
** Seleziona la casella di controllo relativa al tenant e seleziona *Actions* > *Change root password*.
** Seleziona il nome del tenant per visualizzare la pagina dei dettagli e seleziona *Azioni* > *Cambia password di root*.


. Inserisci la nuova password per il tenant account.
. Seleziona *Salva*.
