= Controlla l'accesso a StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi controllare chi può accedere a StorageGRID e quali attività gli utenti possono svolgere creando o importando gruppi e utenti e assegnando le autorizzazioni a ciascun gruppo. Inoltre, puoi abilitare il single sign-on (SSO), creare certificati client e modificare le password della grid.



[[control-access-to-the-grid-manager]]
== Controlla l'accesso al Grid Manager

Puoi determinare chi può accedere a Grid Manager e all'API di gestione di Grid importando gruppi e utenti da un servizio di federazione delle identità oppure configurando gruppi e utenti locali.

Usare link:using-identity-federation.html["federazione di identità"] rende più veloce la configurazione di link:managing-admin-groups.html["gruppi"] e link:managing-users.html["${post_edited_translations.segment}"] e permette agli utenti di accedere a StorageGRID usando le credenziali che già conoscono. Puoi configurare la federazione delle identità se usi Active Directory, OpenLDAP o Oracle Directory Server.


NOTE: ${post_edited_translations.segment}

Puoi determinare quali attività ogni utente può svolgere assegnando diversi link:admin-group-permissions.html["autorizzazioni"] a ciascun gruppo. Ad esempio, potresti voler permettere agli utenti di un gruppo di gestire le regole ILM e agli utenti di un altro gruppo di eseguire attività di manutenzione. Un utente deve appartenere ad almeno un gruppo per accedere al sistema.

Facoltativamente, puoi configurare un gruppo come di sola lettura. Gli utenti di un gruppo di sola lettura possono solo visualizzare le impostazioni e le funzionalità. Non possono apportare modifiche o eseguire operazioni in Grid Manager o Grid Management API.



[[enable-single-sign-on]]
== Abilita single sign-on

Il sistema StorageGRID supporta il single sign-on (SSO) utilizzando lo standard Security Assertion Markup Language 2.0 (SAML 2.0). Dopo aver link:how-sso-works.html["configura e abilita l'SSO"], tutti gli utenti devono essere autenticati da un identity provider esterno prima di poter accedere a Grid Manager, Tenant Manager, Grid Management API o Tenant Management API. Gli utenti locali non possono accedere a StorageGRID.



[[change-provisioning-passphrase]]
== Modifica la passphrase di provisioning

La passphrase di provisioning è necessaria per molte procedure di installazione e manutenzione e per scaricare il pacchetto di ripristino di StorageGRID. La passphrase è inoltre necessaria per scaricare i backup delle informazioni sulla topologia della grid e le chiavi di crittografia per il sistema StorageGRID. Puoi link:changing-provisioning-passphrase.html["${post_edited_translations.segment}"] secondo necessità.



[[change-node-console-passwords]]
== Cambia le password della console del nodo

Ogni nodo della tua griglia ha una password della console del nodo, che ti serve per accedere al nodo come "admin" tramite SSH o come utente root su una connessione alla console VM/fisica. Se necessario, puoi link:change-node-console-password.html["cambia la password della console del nodo"] per ogni nodo.
