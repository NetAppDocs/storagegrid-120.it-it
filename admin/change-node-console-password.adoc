= Modificare le password della console dei nodi in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ogni nodo della tua grid ha una password della console del nodo, che usi per accedere al nodo. Per impostazione predefinita, ogni nodo ha una password univoca. Puoi modificare ciascuna password con una nuova password univoca, oppure puoi modificare la password di ogni nodo per utilizzare una password globale. Le password sono memorizzate nel pacchetto di ripristino.

.Prima di iniziare
* Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].
* Hai il link:admin-group-permissions.html["Permesso di manutenzione o di accesso root"].
* Hai la passphrase di provisioning corrente.


.Informazioni su questa attività
Usi la password della console del nodo per accedere a un nodo come "admin" tramite SSH, oppure come utente root su una connessione alla console VM/fisica. Puoi cambiare le password della console del nodo usando una di queste opzioni:

* Applica automaticamente password casuali a ciascun nodo
* Specifica e applica una password globale a tutti i nodi
* Specifica e applica una password univoca a uno o più nodi


Le password sono memorizzate in un file  `Passwords.txt` aggiornato nel pacchetto di ripristino. Le password sono elencate nella colonna Password nel file.


NOTE: Le link:../admin/change-ssh-access-passwords.html["Password di accesso SSH"] per le chiavi SSH utilizzate per la comunicazione tra i nodi sono separate dalle password della console del nodo. Questa procedura non modifica le password di accesso SSH.



[[access-the-wizard]]
== Accedi al wizard

.Passaggi
. Seleziona *Configurazione* > *Controllo accessi* > *Password griglia*.
. In *Modifica password della console del nodo*, seleziona *Effettua una modifica*.




[[download-currentdownload-the-current-recovery-package]]
== [[download-current]]Scarica il pacchetto di ripristino corrente

Prima di modificare le password della console del nodo, scarica il pacchetto di ripristino corrente. Puoi utilizzare le password in questo file se il processo di modifica della password non riesce per qualsiasi nodo.

.Passaggi
. Inserisci la passphrase di provisioning per la tua grid.
. Seleziona *Scarica il pacchetto di ripristino*.
. Copia il file del pacchetto di ripristino (`.zip` in due posizioni sicure, protette e separate.
+

CAUTION: Il file del pacchetto di ripristino deve essere protetto perché contiene chiavi di crittografia e password che possono essere utilizzate per ottenere dati dal sistema StorageGRID.

. Seleziona *Continue*.




[[provide-new-passwords]]
== Fornisci nuove password

. Seleziona il metodo di cambio password che vuoi usare.
+
** *Automatico*: StorageGRID assegna automaticamente una nuova password casuale per la console a tutti i nodi.
** *Personalizzato*: Fornisci le password della console.




[role="tabbed-block"]
====
.Automatico
--
. Seleziona *Continue*.


--
.Personalizzato
--
. Seleziona una delle seguenti:
+
** *Password globale della console*: Applica la stessa password della console a tutti i nodi.
** *Password univoche per la console*: Applica una password diversa a uno o più nodi.


. Se hai selezionato *Password della console globale*, inserisci la password che vuoi usare per tutti i nodi.
. Se hai selezionato *Password univoche per la console*, inserisci una password univoca per uno o più nodi.
. Seleziona *Continue*.


--
====


[[complete-the-password-change]]
== Completa la modifica della password

. Quando viene visualizzata la finestra di dialogo di conferma, seleziona *Yes* se sei pronto affinché StorageGRID inizi a modificare le password della console del nodo.
+

NOTE: Non puoi annullare questo processo dopo che è stato avviato.

+
StorageGRID genera un nuovo pacchetto di ripristino contenente la nuova password.

. Quando il nuovo pacchetto di ripristino è pronto, seleziona *Scarica nuovo pacchetto di ripristino* e salva il pacchetto di ripristino.
. Apri il file `.zip`.
. Conferma che puoi accedere ai contenuti, incluso il  `Passwords.txt` file che contiene le nuove password della console del nodo.
. Copia il nuovo file del pacchetto di ripristino (`.zip` in due posizioni sicure, protette e separate.
+

CAUTION: Non sovrascrivere il vecchio pacchetto di ripristino.

+
Devi proteggere il file di ripristino, perché contiene chiavi di crittografia e password che possono essere usate per ottenere dati dal sistema StorageGRID.

. Seleziona la casella di controllo per indicare che hai scaricato il nuovo pacchetto di ripristino e verificato il contenuto.
. Seleziona *Continue*.
+
StorageGRID aggiorna la password per ciascun nodo.

+
Se si verifica un errore durante il processo di aggiornamento, la barra di avanzamento mostra il numero di nodi per i quali la modifica della password non è andata a buon fine. Il sistema riprova automaticamente il processo su qualsiasi nodo per il quale la modifica della password non è riuscita. Se al termine del processo alcuni nodi non hanno ancora la password modificata, compare il pulsante *Retry*.

. Se l'aggiornamento della password non è riuscito per uno o più nodi:
+
.. Esamina i messaggi di errore elencati nella tabella.
.. Risolvi i problemi.
.. Seleziona *Riprova*.
+

NOTE: Il nuovo tentativo modifica solo le password della console dei nodi sui nodi che non sono riusciti durante i precedenti tentativi di modifica della password.



. Quando la barra di avanzamento indica che non ci sono più aggiornamenti, seleziona *Fine*.
. Dopo aver modificato le password della console del nodo per tutti i nodi, elimina il <<download-current,primo pacchetto di ripristino che hai scaricato>>.
