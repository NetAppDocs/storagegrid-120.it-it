= Visualizza gli indirizzi IP in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi visualizzare l'indirizzo IP di ciascun nodo della griglia nel tuo sistema StorageGRID. Puoi quindi usare questo indirizzo IP per accedere al nodo della griglia dalla riga di comando ed eseguire varie procedure di manutenzione.

.Prima di iniziare
Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].

.Informazioni su questa attività
Per informazioni sulla modifica degli indirizzi IP, vedi link:../maintain/configuring-ip-addresses.html["Configura gli indirizzi IP"].

.Passaggi
. Seleziona *Nodes* > *_grid node_* > *Overview*.
. Seleziona *Mostra altro* a destra del titolo IP Addresses.
+
Gli indirizzi IP di quel nodo della griglia sono elencati in una tabella.
