= Cambia la password di StorageGRID Grid Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se sei un utente locale di Grid Manager, puoi cambiare la tua password.

.Prima di iniziare
Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].

.Informazioni su questa attività
Se accedi a StorageGRID come utente federato o se il single sign-on (SSO) è abilitato, non puoi modificare la password in Grid Manager. Invece, devi modificare la password nell'origine di identità esterna, ad esempio Active Directory o OpenLDAP.

.Passaggi
. Dall'intestazione di Grid Manager, seleziona *_il tuo nome_* > *Cambia password*.
. Inserisci la tua password attuale.
. Inserisci una nuova password.
+
La tua password deve contenere almeno 8 e non più di 32 caratteri. Le password distinguono tra maiuscole e minuscole.

. ${post_edited_translations.segment}
. Seleziona *Salva*.
