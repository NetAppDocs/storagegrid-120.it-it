= Modificare un account tenant di StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi modificare un account tenant per cambiare il nome visualizzato, la quota di archiviazione o le autorizzazioni del tenant.


TIP: Se un tenant dispone dell'autorizzazione *Usa connessione di federazione griglia*, puoi modificare i dettagli del tenant da entrambe le griglie della connessione. Tuttavia, le modifiche che fai su una griglia della connessione non verranno copiate sull'altra griglia. Se vuoi mantenere i dettagli del tenant perfettamente sincronizzati tra le griglie, apporta le stesse modifiche su entrambe. Vedi link:grid-federation-manage-tenants.html["Gestisci i tenant autorizzati per la connessione alla federazione di rete"].

.Prima di iniziare
* Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].
* Disponi di link:admin-group-permissions.html["Access root o autorizzazione account tenant"].



NOTE: L'applicazione delle impostazioni del tenant all'intera griglia potrebbe richiedere 15 minuti o più, a seconda della connettività di rete, dello stato dei nodi e delle operazioni di Cassandra.
