= Algoritmi di cifratura supportati per le connessioni TLS in uscita in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il sistema StorageGRID supporta un set limitato di suite di cifratura per le connessioni Transport Layer Security (TLS) ai sistemi esterni utilizzati per la federazione delle identità e i Cloud Storage Pools.



[[supported-versions-of-tls]]
== ${post_edited_translations.segment}

StorageGRID supporta TLS 1.2 e TLS 1.3 per le connessioni a sistemi esterni utilizzati per la federazione delle identità e Cloud Storage Pools.

Gli algoritmi di crittografia TLS supportati per l'utilizzo con sistemi esterni sono stati selezionati per garantire la compatibilità con una gamma di sistemi esterni. L'elenco è più ampio rispetto all'elenco degli algoritmi di crittografia supportati per l'utilizzo con le applicazioni client S3. Per configurare gli algoritmi di crittografia, vai su *Configurazione* > *Sicurezza* > *Impostazioni di sicurezza* e seleziona *Criteri TLS e SSH*.


NOTE: Le opzioni di configurazione TLS, come le versioni del protocollo, i cifrari, gli algoritmi di scambio delle chiavi e gli algoritmi MAC, non sono configurabili in StorageGRID. Contatta il tuo referente NetApp per richieste specifiche relative a queste impostazioni.
