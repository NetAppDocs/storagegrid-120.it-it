[[what-is-fabricpool]]
== Cos'è FabricPool?

FabricPool è una soluzione storage ibrida ONTAP che utilizza un aggregate flash dalle performance elevate come livello di prestazioni e un archivio di oggetti come livello cloud. Utilizzare aggregate abilitati FabricPool ti aiuta a ridurre i costi di storage senza compromettere prestazioni, efficienza o protezione.

FabricPool associa un tier cloud (un archivio di oggetti esterno, come StorageGRID) a un tier locale (un aggregato di storage ONTAP) per creare una raccolta composita di dischi. I volumi all'interno di FabricPool possono quindi sfruttare il tiering mantenendo i dati attivi (hot) su uno storage dalle performance elevate (il tier locale) e spostando in tier i dati inattivi (cold) nell'archivio di oggetti esterno (il tier cloud).

Non sono necessarie modifiche architetturali e puoi continuare a gestire i tuoi dati e l'ambiente applicativo dal sistema storage centrale ONTAP.



[[what-is-storagegrid]]
== Cos'è StorageGRID?

NetApp StorageGRID è un'architettura di storage che gestisce i dati come oggetti, a differenza di altre architetture di storage come file o storage a blocchi. Gli oggetti vengono conservati all'interno di un singolo container (come un bucket) e non sono annidati come file all'interno di una directory dentro altre directory. Sebbene lo storage a oggetti offra generalmente prestazioni inferiori rispetto allo storage a file o a blocchi, è significativamente più scalabile. I bucket di StorageGRID possono contenere petabyte di dati e miliardi di oggetti.



[[why-use-storagegrid-as-a-fabricpool-cloud-tier]]
== Perché usare StorageGRID come livello cloud FabricPool?

FabricPool può eseguire il tiering dei dati ONTAP verso diversi provider di storage a oggetti, inclusa StorageGRID. A differenza dei cloud pubblici che potrebbero impostare un numero massimo di operazioni di input/output al secondo (IOPS) supportate a livello di bucket o container, le prestazioni di StorageGRID scalano in base al numero di nodi nel sistema. Utilizzare StorageGRID come livello cloud FabricPool ti permette di mantenere i dati meno utilizzati nel tuo cloud privato per ottenere le massime performance e il controllo completo sui tuoi dati.

Inoltre, non è necessaria una licenza FabricPool quando usi StorageGRID come livello cloud.
