= Crea un bucket S3 e ottieni le chiavi di accesso per FabricPool in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di utilizzare StorageGRID con un carico di lavoro FabricPool, devi creare un bucket S3 per i dati FabricPool. Devi anche ottenere una access key e una secret access key per il tenant account che userai per FabricPool.

Per i dettagli su questa attività, consulta link:../tenant/creating-s3-bucket.html["Crea bucket S3"] e link:../tenant/creating-your-own-s3-access-keys.html["${post_edited_translations.segment}"]. Per utilizzare il setup wizard di FabricPool per completare questa attività, vai su link:use-fabricpool-setup-wizard-steps.html["Accedi e completa la FabricPool setup wizard"].

.Prima di iniziare
* Hai creato un account tenant per l'utilizzo di FabricPool.
* Hai accesso root all'account del tenant.


.Passaggi
. Accedi al Tenant Manager.
+
Puoi fare una delle seguenti cose:

+
** Dalla pagina Tenant Accounts in Grid Manager, seleziona il link *Sign in* per il tenant e inserisci le tue credenziali.
** Inserisci l'URL dell'account tenant in un browser web e inserisci le tue credenziali.


. Crea un bucket S3 per i dati di FabricPool.
+
Devi creare un bucket univoco per ogni ONTAP cluster che vuoi utilizzare.

+
.. ${post_edited_translations.segment}
.. Seleziona *Create bucket*.
.. Inserisci il nome del bucket StorageGRID che desideri utilizzare con FabricPool. Ad esempio, `fabricpool-bucket`.
+

TIP: Non puoi cambiare il nome del bucket dopo aver creato il bucket.

.. ${post_edited_translations.segment}
+
Per impostazione predefinita, tutti i bucket vengono creati nella regione `us-east-1`. Se la regione predefinita è configurata su una regione diversa da `us-east-1`, questa altra regione viene inizialmente selezionata nel menu a discesa.

.. Seleziona *Continue*.
.. Seleziona *Create bucket*.
+

NOTE: Non selezionare *Abilita il versioning degli oggetti* per il bucket FabricPool. Allo stesso modo, non modificare un bucket FabricPool per utilizzare *Disponibile* o una consistenza diversa da quella predefinita. La consistenza consigliata per i bucket FabricPool è *Lettura dopo la nuova scrittura*, che è la consistenza predefinita per un nuovo bucket.



. Crea una chiave di accesso e una chiave di accesso segreta.
+
.. ${post_edited_translations.segment}
.. ${post_edited_translations.segment}
.. Seleziona *Crea access key*.
.. Copia l'ID della chiave di accesso e la chiave di accesso segreta in un luogo sicuro, oppure seleziona *Download .csv* per salvare un file foglio di calcolo contenente l'ID della chiave di accesso e la chiave di accesso segreta.
+
Inserirai questi valori in ONTAP quando configuri StorageGRID come livello cloud FabricPool.

+

TIP: Se in futuro generi una nuova access key e una nuova secret access key in StorageGRID, inserisci le nuove chiavi in ONTAP prima di eliminare i vecchi valori da StorageGRID. Altrimenti, ONTAP potrebbe perdere temporaneamente l'accesso a StorageGRID.
