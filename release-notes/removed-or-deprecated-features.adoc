= Funzionalità e funzionalità rimosse o deprecate in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Scopri le funzionalità e le caratteristiche rimosse o deprecate in StorageGRID 12.0. Prima di eseguire l'aggiornamento, verifica se le funzionalità rimosse o deprecate influiscono sulle tue applicazioni client o sulla configurazione della griglia.



[[definitions]]
== Definizioni

Deprecato:: Questa funzionalità *non dovrebbe* essere utilizzata nei nuovi ambienti di produzione. Gli ambienti di produzione esistenti possono continuare a utilizzarla.
Fine del ciclo di vita:: Ultima versione rilasciata che supporta la funzionalità. In alcuni casi, la documentazione relativa alla funzionalità potrebbe essere rimossa in questa fase.
Rimosso:: Prima versione che *non* supporta la funzionalità.




[[storagegrid-end-of-feature-support]]
== Fine del supporto per le funzionalità di StorageGRID

Le funzionalità deprecate verranno rimosse nelle versioni principali N+2. Per esempio, se una funzionalità viene deprecata nella versione N (per esempio, 6.3), l'ultima versione in cui la funzionalità esisterà è N+1 (per esempio, 6.4). La versione N+2 (per esempio, 6.5) è la prima release in cui la funzionalità non esiste più nel prodotto.

Guarda  https://mysupport.netapp.com/site/info/version-support["Pagina di supporto delle versioni software"^] per ulteriori informazioni.


NOTE: In determinate situazioni, NetApp potrebbe interrompere il supporto per alcune funzionalità prima della data indicata.
