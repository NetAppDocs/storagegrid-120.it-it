= Avvio rapido per gli aggiornamenti di StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di iniziare l'upgrade, esamina il flusso di lavoro generale. La pagina di upgrade di StorageGRID ti guida attraverso ogni fase dell'upgrade.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]Prepara gli host Linux
[role="quick-margin-para"]
Se sono presenti nodi StorageGRID distribuiti su host Linux, link:linux-installing-rpm-or-deb-package-on-all-hosts.html["installare il pacchetto RPM o DEB su ciascun host"] prima di avviare l'upgrade.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]Carica i file di upgrade e di hotfix
[role="quick-margin-para"]
Dal nodo Admin principale, accedi alla pagina di upgrade di StorageGRID e carica il file di upgrade e il file hotfix, se necessario.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]Scarica il pacchetto di ripristino
[role="quick-margin-para"]
Scarica il pacchetto di ripristino più recente prima di avviare l'upgrade.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]Esegui i precheck dell'upgrade
[role="quick-margin-para"]
I controlli preliminari all'upgrade ti aiutano a individuare i problemi, così puoi risolverli prima di iniziare l'upgrade vero e proprio.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinque"] Avvia l'aggiornamento
[role="quick-margin-para"]
Quando avvii l'upgrade, i precheck vengono eseguiti di nuovo e il nodo Admin primario viene aggiornato automaticamente. Non puoi accedere a Grid Manager mentre il nodo Admin primario è in fase di upgrade. Anche i log di audit non saranno disponibili. Questo upgrade può richiedere fino a 30 minuti.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sei"]Scarica il pacchetto di ripristino
[role="quick-margin-para"]
Dopo l'aggiornamento del nodo di amministrazione primario, scarica un nuovo pacchetto di ripristino.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["Sette"] Approva i nodi
[role="quick-margin-para"]
Puoi approvare singoli nodi della griglia, gruppi di nodi della griglia o tutti i nodi della griglia.


CAUTION: Non approvare l'upgrade di un nodo della griglia a meno che tu non sia sicuro che il nodo sia pronto per essere arrestato e riavviato.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-8.png["Otto"]Riprendi le operazioni
[role="quick-margin-para"]
Una volta aggiornati tutti i nodi della griglia, vengono abilitate le nuove funzionalità e puoi riprendere le operazioni. Devi aspettare a eseguire una procedura di decommission o espansione finché le attività in background *Upgrade database* e *Final upgrade steps* non sono state completate.
