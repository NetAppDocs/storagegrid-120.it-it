= Aggiorna il software StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Segui queste istruzioni per aggiornare un sistema StorageGRID a una nuova versione.

Quando esegui l'upgrade, tutti i nodi nel tuo sistema StorageGRID vengono aggiornati.


CAUTION: Non avviare l'upgrade se hai urgente bisogno di espandere il tuo storage per aumentare la capacità (se il tuo storage è quasi pieno). Completa la procedura di upgrade in modo tempestivo. Se è necessario un recovery, contatta il supporto tecnico.
