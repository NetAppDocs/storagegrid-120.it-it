= Ottieni i materiali necessari per un aggiornamento del software StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di iniziare l'aggiornamento del software, procurati tutto il materiale necessario.

[cols="1a,3a"]
|===
| Articolo | Note 


 a| 
Portatile di servizio
 a| 
Il computer portatile di servizio deve avere:

* ${post_edited_translations.segment}
* ${post_edited_translations.segment}




 a| 
link:../admin/web-browser-requirements.html["${post_edited_translations.segment}"]
 a| 
Il supporto dei browser in genere cambia a ogni release di StorageGRID. Assicurati che il tuo browser sia compatibile con la nuova versione di StorageGRID.



 a| 
Passphrase di provisioning
 a| 
La passphrase viene creata e documentata quando il sistema StorageGRID viene installato per la prima volta. La passphrase di provisioning non è presente nel  `Passwords.txt` file.



 a| 
Archivio Linux RPM o DEB
 a| 
Se hai nodi distribuiti su host Linux, devi link:linux-installing-rpm-or-deb-package-on-all-hosts.html["scarica e installa il pacchetto RPM o DEB su tutti gli host"] prima di iniziare l'upgrade.

Assicurati che il tuo sistema operativo Linux soddisfi i requisiti minimi di versione del kernel di StorageGRID. Vedi link:../swnodes/installing-linux.html["Installa StorageGRID sugli host Linux"].
