= Risoluzione dei problemi di aggiornamento di StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se si verifica un problema durante l'aggiornamento, potresti essere in grado di risolverlo autonomamente. Se non riesci a risolverlo, raccogli quante più informazioni possibili e poi contatta il supporto tecnico.



[[upgrade-does-not-complete]]
== ${post_edited_translations.segment}

${post_edited_translations.segment}



[[upgrade-precheck-errors]]
=== ${post_edited_translations.segment}

Per individuare e risolvere i problemi, puoi eseguire manualmente i controlli preliminari dell'aggiornamento prima di iniziare l'aggiornamento vero e proprio. La maggior parte degli errori dei controlli preliminari fornisce informazioni su come risolvere il problema.



[[provisioning-failures]]
=== ${post_edited_translations.segment}

Se il processo di provisioning automatico non va a buon fine, contatta il supporto tecnico.



[[grid-node-crashes-or-fails-to-start]]
=== Il nodo della griglia si blocca o non si avvia

Se un nodo della griglia si blocca durante il processo di aggiornamento o non si avvia correttamente al termine dell'aggiornamento, contatta il supporto tecnico per indagare e risolvere eventuali problemi sottostanti.



[[ingest-or-data-retrieval-is-interrupted]]
=== L'acquisizione o il recupero dei dati è interrotto

Se l'acquisizione o il recupero dei dati si interrompe inaspettatamente quando non stai aggiornando un nodo della griglia, contatta il supporto tecnico.



[[database-upgrade-errors]]
=== Errori di aggiornamento del database

Se l'aggiornamento del database non riesce e viene visualizzato un errore, riprova l'aggiornamento. Se il problema persiste, contatta il supporto tecnico.

.Informazioni correlate
link:checking-systems-condition-before-upgrading-software.html["Controlla le condizioni del sistema prima di aggiornare il software"]



[[user-interface-issues]]
== Problemi dell'interfaccia utente

Potresti riscontrare problemi con Grid Manager o Tenant Manager durante o dopo l'aggiornamento.



[[grid-manager-displays-multiple-error-messages-during-upgrade]]
=== Grid Manager visualizza diversi messaggi di errore durante l'aggiornamento

Se aggiorni il browser o navighi verso un'altra pagina di Grid Manager mentre il nodo di amministrazione principale è in fase di aggiornamento, potresti visualizzare più messaggi "503: Service Unavailable" e "Problem connecting to the server". Puoi tranquillamente ignorare questi messaggi: smetteranno di apparire non appena il nodo sarà aggiornato.

Se questi messaggi vengono visualizzati per più di un'ora dopo l'avvio dell'aggiornamento, potrebbe essersi verificato un problema che ha impedito l'aggiornamento del nodo di amministrazione primario. Se non riesci a risolvere il problema autonomamente, contatta il supporto tecnico.



[[web-interface-does-not-respond-as-expected]]
=== L'interfaccia web non risponde come previsto

Grid Manager o Tenant Manager potrebbero non rispondere come previsto dopo l'aggiornamento del software StorageGRID.

Se riscontri problemi con l'interfaccia web:

* Assicurati di utilizzare un link:../admin/web-browser-requirements.html["browser web supportato"].
+

NOTE: Il supporto dei browser in genere cambia a ogni release di StorageGRID.

* Cancella la cache del browser web.
+
La cancellazione della cache rimuove le risorse obsolete utilizzate dalla versione precedente del software StorageGRID e permette all'interfaccia utente di funzionare di nuovo correttamente. Per le istruzioni, consulta la documentazione del tuo browser web.





[[docker-image-availability-check-error-messages]]
== Messaggi di errore "Docker image availability check"

Quando tenti di avviare il processo di aggiornamento, potresti ricevere un messaggio di errore che dice "La suite di convalida per il controllo della disponibilità delle immagini Docker ha rilevato i seguenti problemi". Tutti i problemi devono essere risolti prima che tu possa completare l'aggiornamento.

Contatta il supporto tecnico se non sei sicuro delle modifiche necessarie per risolvere i problemi riscontrati.
