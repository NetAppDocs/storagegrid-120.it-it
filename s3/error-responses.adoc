[[storagegrid-custom-error-codes]]
== Codici di errore personalizzati di StorageGRID

[cols="2a,2a,1a"]
|===
| Nome | Descrizione | stato HTTP 


 a| 
XBucketLifecycleNotAllowed
 a| 
La configurazione del ciclo di vita del bucket non è consentita in un bucket Compliant legacy
 a| 
400 Richiesta non valida



 a| 
XBucketPolicyParseException
 a| 
Impossibile analizzare il JSON della bucket policy ricevuta.
 a| 
400 Richiesta non valida



 a| 
XComplianceConflict
 a| 
Operazione negata a causa di impostazioni di Compliance obsolete.
 a| 
403 Vietato



 a| 
XComplianceRiduzioneRidondanzaVietato
 a| 
La ridondanza ridotta non è consentita nel bucket Compliant legacy
 a| 
400 Richiesta non valida



 a| 
XMaxBucketPolicyLengthExceeded
 a| 
La tua policy supera la lunghezza massima consentita per la policy del bucket.
 a| 
400 Richiesta non valida



 a| 
XMissingInternalRequestHeader
 a| 
Manca un'intestazione in una richiesta interna.
 a| 
400 Richiesta non valida



 a| 
XNoSuchBucketCompliance
 a| 
Il bucket specificato non ha la Compliance legacy abilitata.
 a| 
404 Non trovato



 a| 
XNotAcceptable
 a| 
La richiesta contiene una o più intestazioni di accettazione che non possono essere soddisfatte.
 a| 
406 Non accettabile



 a| 
XNotImplemented
 a| 
La richiesta che hai fornito implica una funzionalità che non è implementata.
 a| 
501 Non implementato

|===
