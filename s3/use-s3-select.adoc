= Operazioni Amazon S3 Select supportate in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID supporta le seguenti clausole Amazon S3 Select, tipi di dati e operatori per il link:select-object-content.html["comando SelectObjectContent"].


NOTE: Gli articoli non elencati non sono supportati.

Per la sintassi, vedi link:select-object-content.html["SelectObjectContent"]. Per ulteriori informazioni su S3 Select, vedi  https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html["Documentazione AWS per S3 Select"^].

Solo gli account tenant che hanno S3 Select abilitato possono eseguire query SelectObjectContent. Vedi link:../admin/manage-s3-select-for-tenant-accounts.html["Considerazioni e requisiti per l'utilizzo di S3 Select"].
