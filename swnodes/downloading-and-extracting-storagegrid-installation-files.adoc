= Scarica ed estrai i file di installazione di StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Devi scaricare l'archivio di installazione di StorageGRID ed estrarre i file richiesti. Facoltativamente, puoi verificare manualmente i file presenti nel pacchetto di installazione.

.Passaggi
. Vai al https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp Downloads page per StorageGRID"^].
. Seleziona il pulsante per scaricare l'ultima release oppure seleziona un'altra versione dal menu a tendina e seleziona *Go*.
. Accedi con il nome utente e la password del tuo account NetApp.
. Se compare un avviso/MustRead, leggilo e seleziona la casella di controllo.
+

CAUTION: Devi applicare tutti gli hotfix richiesti dopo aver installato la release di StorageGRID. Per ulteriori informazioni, vedi la link:../maintain/storagegrid-hotfix-procedure.html["procedura di hotfix nelle istruzioni di recovery e manutenzione"]

. Leggi il Contratto di licenza per l'utente finale, seleziona la casella di controllo e poi seleziona *Accetta e continua*.
. Nella colonna *Installa StorageGRID*, seleziona l'archivio di installazione .tgz o .zip per il tuo tipo di nodo basato su software: RHEL, Ubuntu o Debian, oppure VMware.
+

NOTE: Utilizza il file  `.zip` se stai usando Windows sul portatile di servizio.

. Salva l'archivio di installazione.
. [[download-verification-package]]La verifica della firma del codice è manuale su un nodo Linux. Facoltativamente, se devi verificare l'archivio di installazione:
+
.. Scarica il pacchetto di verifica della firma del codice di StorageGRID. Il nome del file di questo pacchetto utilizza il formato  `StorageGRID_<version-number>_Code_Signature_Verification_Package.tar.gz`, dove  `<version-number>` è la versione del software StorageGRID.
.. Segui i passaggi per link:download-files-verify.html["verifica manualmente i file di installazione"].


. Estrai i file dall'archivio di installazione.
. Scegli i file di cui hai bisogno.
+
I file di cui hai bisogno dipendono dalla topologia della griglia che prevedi e da come distribuirai il tuo sistema StorageGRID.

+

NOTE: I percorsi elencati nella tabella sono relativi alla directory di livello superiore installata dall'archivio di installazione estratto.



[role="tabbed-block"]
====
.RHEL
--
[cols="1a,1a"]
|===
| Percorso e nome file | Descrizione 


| ./rpms/README  a| 
Un file di testo che descrive tutti i file contenuti nel file di download di StorageGRID.



| ./rpms/NLF000000.txt  a| 
Una licenza gratuita che non prevede alcun diritto di supporto per il prodotto.



| ./rpms/StorageGRID-Webscale-Images-_version_-SHA.rpm  a| 
Pacchetto RPM per installare le immagini dei nodi StorageGRID sui tuoi host RHEL.



| ./rpms/StorageGRID-Webscale-Service-_version_-SHA.rpm  a| 
Pacchetto RPM per installare il servizio host StorageGRID sui tuoi host RHEL.



| Strumento di scripting per la distribuzione | Descrizione 


| ./rpms/configure-storagegrid.py  a| 
Uno script Python utilizzato per automatizzare la configurazione di un sistema StorageGRID.



| ./rpms/configure-sga.py  a| 
Uno script Python utilizzato per automatizzare la configurazione delle appliance StorageGRID.



| ./rpms/configure-storagegrid.sample.json  a| 
Un esempio di file di configurazione da utilizzare con lo script  `configure-storagegrid.py`.



| ./rpms/storagegrid-ssoauth.py  a| 
Un esempio di script Python che puoi utilizzare per accedere all'API Grid Management quando il single sign-on è abilitato. Puoi utilizzare questo script anche per l'integrazione con Ping Federate.



| ./rpms/configure-storagegrid.blank.json  a| 
Un file di configurazione vuoto da utilizzare con lo  `configure-storagegrid.py` script.



| ./rpms/extras/ansible  a| 
Esempio di ruolo e playbook Ansible per la configurazione di host RHEL per il deployment di container StorageGRID. Puoi personalizzare il ruolo o il playbook se necessario.



| ./rpms/storagegrid-ssoauth-azure.py  a| 
Ecco un esempio di script Python che puoi utilizzare per accedere all'API di gestione della griglia quando il single sign-on (SSO) è abilitato tramite Active Directory o Ping Federate.



| ./rpms/storagegrid-ssoauth-azure.js  a| 
Uno script di supporto richiamato dallo script Python di accompagnamento `storagegrid-ssoauth-azure.py` per eseguire interazioni SSO con Azure.



| ./rpms/extras/api-schemas  a| 
Schemi API per StorageGRID.

*Nota*: Prima di eseguire un aggiornamento, puoi usare questi schemi per confermare che qualsiasi codice tu abbia scritto per utilizzare le API di gestione di StorageGRID sarà compatibile con la nuova release di StorageGRID, se non hai un ambiente StorageGRID non di produzione per testare la compatibilità dell'aggiornamento.
