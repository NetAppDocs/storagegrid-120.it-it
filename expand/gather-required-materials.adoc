= Preparati ad espandere il tuo sistema StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di eseguire un'operazione di espansione, raccogli i materiali e installa e configura qualsiasi nuovo hardware e rete.

[cols="1a,2a"]
|===
| Articolo | Note 


 a| 
Archivio di installazione StorageGRID
 a| 
Se stai aggiungendo nuovi nodi alla griglia o un nuovo sito, devi scaricare ed estrarre l'archivio di installazione di StorageGRID. Devi utilizzare la stessa versione attualmente in esecuzione sulla griglia.

Per i dettagli, consulta le istruzioni per <<download-and-extract-install-files,download ed estrazione dei file di installazione di StorageGRID>>.

*Nota:* Non devi scaricare i file se aggiungi nuovi volumi di storage a Storage Node esistenti o installi una nuova StorageGRID appliance.



 a| 
Portatile di servizio
 a| 
Il computer portatile di servizio ha quanto segue:

* Porta di rete
* Client SSH (ad esempio, PuTTY)
* link:../admin/web-browser-requirements.html["Browser web supportati"]




 a| 
`Passwords.txt` file
 a| 
Contiene le password necessarie per accedere ai nodi della griglia tramite riga di comando. Incluso nel pacchetto di ripristino.



 a| 
Passphrase di provisioning
 a| 
La passphrase viene creata e documentata quando il sistema StorageGRID viene installato per la prima volta. La passphrase di provisioning non è presente nel file `Passwords.txt`.



 a| 
Documentazione di StorageGRID
 a| 
* link:../admin/index.html["Gestisci StorageGRID"]
* https://library.netapp.com/ecm/ecm_download_file/ECMLP3351267["Note di rilascio"^]. È necessario accedere con il proprio account NetApp o crearne uno per accedere alle note di rilascio.
* link:../swnodes/index.html["Istruzioni di installazione per la tua piattaforma"]




 a| 
Documentazione aggiornata per la tua piattaforma
 a| 
Per le versioni supportate, consulta la https://imt.netapp.com/matrix/#welcome["Interoperability Matrix Tool (IMT)"^].

|===


[[download-and-extract-the-storagegrid-installation-files]]
== Scarica ed estrai i file di installazione di StorageGRID

.[[scarica-e-estrai-i-file-di-installazione]]
Prima di poter aggiungere nuovi nodi alla griglia o un nuovo sito, devi scaricare l'archivio di installazione di StorageGRID appropriato ed estrarre i file.

.Informazioni su questa attività
Devi eseguire le operazioni di espansione utilizzando la versione di StorageGRID attualmente in esecuzione sulla griglia.

.Passaggi
. Vai a https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["Download NetApp: StorageGRID"^].
. Seleziona la versione di StorageGRID attualmente in esecuzione sulla griglia.
. Accedi con il nome utente e la password del tuo account NetApp.
. Leggi il Contratto di licenza per l'utente finale, seleziona la casella di controllo e poi seleziona *Accetta e continua*.
. Nella colonna *Installa StorageGRID* della pagina di download, seleziona il  `.tgz` o  `.zip` file per la tua piattaforma.
+
La versione indicata nel file di archivio di installazione deve corrispondere alla versione del software attualmente installato.

+
Utilizza il file  `.zip` se stai usando Windows sul portatile di servizio.

+

[[verify-hardware-and-networking]]
== Verifica hardware e rete

Prima di iniziare l'espansione del tuo sistema StorageGRID, assicurati di quanto segue:

* L'hardware necessario per supportare i nuovi nodi della griglia o il nuovo sito è stato installato e configurato.
* Tutti i nuovi nodi hanno percorsi di comunicazione bidirezionali con tutti i nodi esistenti e nuovi (un requisito per la rete Grid). In particolare, conferma che le seguenti porte TCP siano aperte tra i nuovi nodi che stai aggiungendo nell'espansione e il nodo Admin primario:
+
** 1055
** 7443
** 8011
** 10342


+
Vedi link:../network/internal-grid-node-communications.html["Comunicazioni interne dei nodi della grid"].

* Il nodo amministratore primario può comunicare con tutti i server di espansione destinati a ospitare il sistema StorageGRID.
* Se uno qualsiasi dei nuovi nodi ha un indirizzo IP della Grid Network su una sottorete non utilizzata in precedenza, hai già link:updating-subnets-for-grid-network.html["aggiunto la nuova sottorete"] nell'elenco delle sottoreti della Grid Network. Altrimenti, dovrai annullare l'espansione, aggiungere la nuova sottorete e ricominciare la procedura.
* Non stai utilizzando la traduzione degli indirizzi di rete (NAT) sulla Grid Network tra i nodi della griglia o tra i siti StorageGRID. Quando usi indirizzi IPv4 privati per la Grid Network, quegli indirizzi devono essere direttamente instradabili da ogni nodo della griglia in ogni sito. L'utilizzo del NAT per collegare la Grid Network attraverso un segmento di rete pubblica è supportato solo se usi un'applicazione di tunneling trasparente per tutti i nodi della griglia, cioè i nodi della griglia non devono conoscere gli indirizzi IP pubblici.
+
Questa restrizione NAT è specifica per i nodi della griglia e la Grid Network. Se necessario, puoi usare il NAT tra client esterni e nodi della griglia, ad esempio per fornire un indirizzo IP pubblico a un Gateway Node.
