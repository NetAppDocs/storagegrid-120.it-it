= Aggiungi o aggiorna le subnet alla Grid Network per l'espansione in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando aggiungi nodi alla griglia o un nuovo sito in un'espansione, potresti dover aggiornare o aggiungere sottoreti alla Grid Network.

StorageGRID mantiene un elenco delle sottoreti di rete utilizzate per la comunicazione tra i nodi del grid sulla Grid Network (eth0). Queste voci includono le sottoreti utilizzate per la Grid Network da ciascun sito nel tuo sistema StorageGRID, così come eventuali sottoreti utilizzate per NTP, DNS, LDAP o altri server esterni accessibili tramite il gateway della Grid Network.

.Prima di iniziare
* Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].
* Hai il link:../admin/admin-group-permissions.html["Permesso di manutenzione o di accesso root"].
* Hai la passphrase di provisioning.
* Hai gli indirizzi di rete, in notazione CIDR, delle subnet che vuoi configurare.


.Informazioni su questa attività
Se uno dei nuovi nodi ha un indirizzo IP della Grid Network su una sottorete non utilizzata in precedenza, devi aggiungere la nuova sottorete all'elenco delle sottoreti della Grid Network prima di iniziare l'espansione. Altrimenti, dovrai annullare l'espansione, aggiungere la nuova sottorete e ricominciare la procedura.

[NOTE]
====
Non utilizzare sottoreti che contengono i seguenti indirizzi IPv4 per la Grid Network, l'Admin Network o la Client Network di alcun nodo:

* 192.168.130.101
* 192.168.130.121
* 192.168.131.101
* 192.168.131.121
* 192.168.130.102
* 192.168.130.122
* 192.168.131.102
* 192.168.131.122
* 198.51.100.2
* 198.51.100.4


Ad esempio, non utilizzare i seguenti intervalli di sottoreti per la Grid Network, l'Admin Network o la Client Network di alcun nodo:

* 192.168.130.0/24 perché questo intervallo di sottorete contiene gli indirizzi IP 192.168.130.101 e 192.168.130.102
* 192.168.131.0/24 perché questo intervallo di sottorete contiene gli indirizzi IP 192.168.131.101 e 192.168.131.102
* 198.51.100.0/24 perché questo intervallo di sottorete contiene gli indirizzi IP 198.51.100.2 e 198.51.100.4


====
.Passaggi
. Seleziona *Manutenzione* > *Rete* > *Grid Network*.
. Seleziona *Aggiungi un'altra sottorete* per aggiungere una nuova sottorete in notazione CIDR.
+
Ad esempio, inserisci  `10.96.104.0/22`.

. Inserisci la passphrase di provisioning e seleziona *Salva*.
. Attendi che le modifiche vengano applicate, quindi scarica un nuovo pacchetto di ripristino.
+
.. Seleziona *Maintenance* > *System* > *Recovery package*.
.. Inserisci la *passphrase di provisioning*.
+

CAUTION: Il file del pacchetto di ripristino deve essere protetto perché contiene chiavi di crittografia e password che possono essere utilizzate per ottenere dati dal sistema StorageGRID. Viene utilizzato anche per ripristinare il nodo Admin primario.





Le sottoreti che hai specificato vengono configurate automaticamente per il tuo sistema StorageGRID.
