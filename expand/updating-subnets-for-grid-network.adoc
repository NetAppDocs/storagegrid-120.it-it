= Aggiungi o aggiorna le subnet alla Grid Network per l'espansione in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando aggiungi nodi alla griglia o un nuovo sito in un'espansione, potresti dover aggiornare o aggiungere sottoreti alla Grid Network.

StorageGRID mantiene un elenco delle sottoreti di rete utilizzate per la comunicazione tra i nodi del grid sulla Grid Network (eth0). Queste voci includono le sottoreti utilizzate per la Grid Network da ciascun sito nel tuo sistema StorageGRID, così come eventuali sottoreti utilizzate per NTP, DNS, LDAP o altri server esterni accessibili tramite il gateway della Grid Network.

.Prima di iniziare
* Sei connesso a Grid Manager utilizzando un link:../admin/web-browser-requirements.html["browser web supportato"].
* Hai il link:../admin/admin-group-permissions.html["Permesso di manutenzione o di accesso root"].
* ${post_edited_translations.segment}
* Hai gli indirizzi di rete, in notazione CIDR, delle subnet che vuoi configurare.


.Informazioni su questa attività
Se uno dei nuovi nodi ha un indirizzo IP della Grid Network su una sottorete non utilizzata in precedenza, devi aggiungere la nuova sottorete all'elenco delle sottoreti della Grid Network prima di iniziare l'espansione. Altrimenti, dovrai annullare l'espansione, aggiungere la nuova sottorete e ricominciare la procedura.
