= Messaggio di audit ORLM per le regole ILM soddisfatte in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Questo messaggio viene generato quando l'oggetto viene memorizzato e copiato correttamente secondo le regole ILM.


NOTE: Il messaggio ORLM non viene generato quando un oggetto viene memorizzato correttamente dalla regola predefinita "Crea 2 copie" se un'altra regola nella policy utilizza il filtro avanzato "Dimensione oggetto".

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
BUID
 a| 
Header del bucket
 a| 
Campo ID del bucket. Utilizzato per operazioni interne. Viene visualizzato solo se STAT è PRGD.



 a| 
CBID
 a| 
Identificatore del blocco di contenuto
 a| 
Il CBID dell'oggetto.



 a| 
CSIZ
 a| 
Dimensione del contenuto
 a| 
La dimensione dell'oggetto in byte.



 a| 
LOCS
 a| 
Posizioni
 a| 
La posizione di archiviazione dei dati dell'oggetto all'interno del sistema StorageGRID. Il valore per LOCS è " se l'oggetto non ha posizioni (ad esempio, è stato eliminato).

CLEC: per gli oggetti con codifica di cancellazione, l'ID del profilo di codifica di cancellazione e l'ID del gruppo di codifica di cancellazione applicato ai dati dell'oggetto.

CLDI: per gli oggetti replicati, l'ID del nodo LDR e l'ID del volume della posizione dell'oggetto.

CLNL: ID del nodo ARC della posizione dell'oggetto se i dati dell'oggetto sono archiviati.



 a| 
PATH
 a| 
Bucket/chiave S3
 a| 
Il nome del bucket S3 e il nome della chiave S3.



 a| 
RSLT
 a| 
Risultato
 a| 
Il risultato dell'operazione ILM.

SUCS: L'operazione ILM è stata un successo.



 a| 
REGOLA
 a| 
Etichetta delle regole
 a| 
L'etichetta leggibile assegnata alla regola ILM applicata a questo oggetto.



 a| 
SEGC
 a| 
UUID del container
 a| 
UUID del container per l'oggetto segmentato. Questo valore è disponibile solo se l'oggetto è segmentato.



 a| 
SGCB
 a| 
CBID del container
 a| 
CBID del container per l'oggetto segmentato. Questo valore è disponibile solo per oggetti segmentati e multipart.



 a| 
STAT
 a| 
Stato
 a| 
Lo stato dell'operazione ILM.

FATTO: Le operazioni ILM sull'oggetto sono completate.

DFER: L'oggetto è stato contrassegnato per una futura rivalutazione dell'ILM.

PRGD: L'oggetto è stato eliminato dal sistema StorageGRID.

NLOC: I dati dell'oggetto non sono più reperibili nel sistema StorageGRID. Questo stato potrebbe indicare che tutte le copie dei dati dell'oggetto sono mancanti o danneggiate.



 a| 
UUID
 a| 
Identificatore univoco universale
 a| 
L'identificativo dell'oggetto all'interno del sistema StorageGRID.



 a| 
VSID
 a| 
ID versione
 a| 
L'ID di versione di un nuovo oggetto creato in un bucket con versione. Le operazioni su bucket e oggetti in bucket senza versione non includono questo campo.

|===
Il messaggio di controllo ORLM può essere emesso più di una volta per un singolo oggetto. Ad esempio, viene emesso ogni volta che si verifica uno dei seguenti eventi:

* Le regole ILM per l'oggetto sono soddisfatte per sempre.
* Le regole ILM per l'oggetto sono soddisfatte per quest'epoca.
* Le regole ILM hanno eliminato l'oggetto.
* Il processo di verifica in background rileva che una copia dei dati di un oggetto replicato è danneggiata. Il sistema StorageGRID esegue una valutazione ILM per sostituire l'oggetto danneggiato.
