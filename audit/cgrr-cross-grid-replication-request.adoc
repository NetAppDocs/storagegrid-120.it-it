= Messaggio di audit CGRR per le richieste di replica tra griglie in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Questo messaggio viene generato quando StorageGRID tenta un'operazione di replica tra griglie per replicare oggetti tra bucket in una connessione di federazione di griglia.

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CSIZ
 a| 
Dimensioni dell'oggetto
 a| 
La dimensione dell'oggetto in byte.

L'attributo CSIZ è stato introdotto in StorageGRID 11.8. Di conseguenza, le richieste di replica cross-grid durante un aggiornamento da StorageGRID 11.7 a 11.8 potrebbero presentare una dimensione totale dell'oggetto imprecisa.



 a| 
S3AI
 a| 
ID account tenant S3
 a| 
L'ID del tenant che possiede il bucket da cui viene replicato l'oggetto.



 a| 
GFID
 a| 
ID connessione Grid federation
 a| 
L'ID della connessione di federazione della griglia utilizzata per la replica tra griglie.



 a| 
OPER
 a| 
Operazione CGR
 a| 
Il tipo di operazione di replica cross-grid che hai tentato:

* 0 = Replica oggetto
* 1 = Replica oggetto multipart
* 2 = Replica il marcatore di eliminazione




 a| 
S3BK
 a| 
Bucket S3
 a| 
Il nome del bucket S3.



 a| 
S3KY
 a| 
Chiave S3
 a| 
Il nome della chiave S3, escluso il nome del bucket.



 a| 
VSID
 a| 
ID versione
 a| 
L'ID della versione specifica di un oggetto che veniva replicata.



 a| 
RSLT
 a| 
Codice risultato
 a| 
Restituisce successo (SUCS) o errore generale (GERR).

|===
