= Messaggio di audit IDEL per le eliminazioni avviate da ILM in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Questo messaggio viene generato quando ILM avvia il processo di eliminazione di un oggetto.

Il messaggio IDEL viene generato in una di queste situazioni:

* *Per gli oggetti nei bucket S3 conformi*: questo messaggio viene generato quando ILM avvia il processo di eliminazione automatica di un oggetto perché il suo periodo di conservazione è scaduto (supponendo che l'impostazione di eliminazione automatica sia abilitata e che il blocco legale sia disattivato).
* *Per gli oggetti in bucket S3 non conformi*. Questo messaggio viene generato quando ILM avvia il processo di eliminazione di un oggetto perché al momento non si applicano istruzioni di posizionamento nelle policy ILM attive all'oggetto stesso.


[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CBID
 a| 
Identificatore del blocco di contenuto
 a| 
Il CBID dell'oggetto.



 a| 
CMPA
 a| 
Conformità: eliminazione automatica
 a| 
Solo per oggetti in bucket S3 conformi. 0 (falso) o 1 (vero), indica se un oggetto conforme deve essere eliminato automaticamente quando termina il suo periodo di conservazione, a meno che il bucket non sia soggetto a un blocco legale.



 a| 
CMPL
 a| 
Conformità: Legal hold
 a| 
Solo per gli oggetti nei bucket S3 conformi. 0 (falso) o 1 (vero), che indica se il bucket è attualmente sottoposto a un blocco legale.



 a| 
CMPR
 a| 
Conformità: periodo di conservazione
 a| 
Solo per oggetti in bucket S3 conformi. La durata del periodo di conservazione dell'oggetto in minuti.



 a| 
CTME
 a| 
Conformità: tempo di ingestione
 a| 
Solo per oggetti in bucket S3 conformi. Ora di inserimento dell'oggetto. Puoi aggiungere il periodo di conservazione in minuti a questo valore per determinare quando l'oggetto può essere eliminato dal bucket.



 a| 
DMRK
 a| 
ID versione del marcatore di eliminazione
 a| 
L'ID della versione del marcatore di eliminazione creato quando elimini un oggetto da un bucket versionato. Le operazioni sui bucket non includono questo campo.



 a| 
CSIZ
 a| 
Dimensione del contenuto
 a| 
La dimensione dell'oggetto in byte.



 a| 
LOCS
 a| 
Posizioni
 a| 
La posizione di archiviazione dei dati dell'oggetto all'interno del sistema StorageGRID. Il valore per LOCS è " se l'oggetto non ha posizioni (ad esempio, è stato eliminato).

CLEC: per gli oggetti con codifica di cancellazione, l'ID del profilo di codifica di cancellazione e l'ID del gruppo di codifica di cancellazione applicato ai dati dell'oggetto.

CLDI: per gli oggetti replicati, l'ID del nodo LDR e l'ID del volume della posizione dell'oggetto.

CLNL: ID del nodo ARC della posizione dell'oggetto se i dati dell'oggetto sono archiviati.



 a| 
PATH
 a| 
Bucket/chiave S3
 a| 
Il nome del bucket S3 e il nome della chiave S3.



 a| 
RSLT
 a| 
Risultato
 a| 
Il risultato dell'operazione ILM.

SUCS: L'operazione ILM è stata un successo.



 a| 
REGOLA
 a| 
Etichetta delle regole
 a| 
* Se un oggetto in un bucket S3 conforme viene eliminato automaticamente perché il suo periodo di conservazione è scaduto, questo campo è vuoto.
* Se l'oggetto viene eliminato perché non ci sono più istruzioni di posizionamento attualmente applicabili all'oggetto, questo campo mostra l'etichetta leggibile dell'ultima regola ILM che è stata applicata all'oggetto.




 a| 
SGRP
 a| 
Sito (gruppo)
 a| 
Se presente, l'oggetto è stato eliminato nel sito specificato, che non è il sito in cui l'oggetto è stato acquisito.



 a| 
UUID
 a| 
Identificatore univoco universale
 a| 
L'identificativo dell'oggetto all'interno del sistema StorageGRID.



 a| 
VSID
 a| 
ID versione
 a| 
L'ID della versione specifica dell'oggetto eliminato. Le operazioni sui bucket e sugli oggetti nei bucket senza versione non includono questo campo.

|===
