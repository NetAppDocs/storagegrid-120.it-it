= Messaggio di audit SPOS per le transazioni S3 POST in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando un client S3 invia una richiesta POST Object, il server emette questo messaggio se la transazione ha esito positivo.

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CBID
 a| 
Identificatore del blocco di contenuto
 a| 
L'identificativo univoco del blocco di contenuto richiesto. Se il CBID non è noto, questo campo viene impostato a 0.



 a| 
CNCH
 a| 
Intestazione di controllo della coerenza
 a| 
Il valore dell'intestazione HTTP Consistency-Control, se presente nella richiesta.



 a| 
CNID
 a| 
Identificatore di connessione
 a| 
L'identificativo univoco del sistema per la connessione TCP/IP.



 a| 
CSIZ
 a| 
Dimensione del contenuto
 a| 
La dimensione dell'oggetto recuperato in byte.



 a| 
HTRH
 a| 
Intestazione della richiesta HTTP
 a| 
Elenco dei nomi e dei valori delle intestazioni delle richieste HTTP registrate come selezionato durante la configurazione.

 `X-Forwarded-For` viene incluso automaticamente se è presente nella richiesta e se il  `X-Forwarded-For` valore è diverso dall'indirizzo IP del mittente della richiesta (campo di audit SAIP).

(Non previsto per SPOS).



 a| 
RSLT
 a| 
Codice risultato
 a| 
Risultato della richiesta RestoreObject. Risultato è sempre:

SUCS: Operazione riuscita



 a| 
S3AI
 a| 
ID account tenant S3 (mittente della richiesta)
 a| 
L'ID account tenant dell'utente che ha inviato la richiesta. Un valore vuoto indica accesso anonimo.



 a| 
S3AK
 a| 
ID della chiave di accesso S3 (mittente della richiesta)
 a| 
L'ID della chiave di accesso S3 con hash per l'utente che ha inviato la richiesta. Un valore vuoto indica un accesso anonimo.



 a| 
S3BK
 a| 
Bucket S3
 a| 
Il nome del bucket S3.



 a| 
S3KY
 a| 
Chiave S3
 a| 
Il nome della chiave S3, escluso il nome del bucket. Le operazioni sui bucket non includono questo campo.



 a| 
S3SR
 a| 
Sottorisorsa S3
 a| 
Il bucket o la sottorisorsa oggetto su cui stai operando, se applicabile.

Imposta su "select" per un'operazione S3 Select.



 a| 
SACC
 a| 
Nome account tenant S3 (mittente della richiesta)
 a| 
Il nome dell'account tenant per l'utente che ha inviato la richiesta. Vuoto per le richieste anonime.



 a| 
SAIP
 a| 
Indirizzo IP (mittente della richiesta)
 a| 
L'indirizzo IP dell'applicazione client che ha effettuato la richiesta.



 a| 
SBAC
 a| 
Nome account tenant S3 (proprietario del bucket)
 a| 
Il nome dell'account tenant per il proprietario del bucket. Usato per identificare l'accesso tra account o l'accesso anonimo.



 a| 
SBAI
 a| 
ID account tenant S3 (proprietario del bucket)
 a| 
L'ID account tenant del proprietario del bucket di destinazione. Usato per identificare l'accesso cross-account o l'accesso anonimo.



 a| 
SRCF
 a| 
Configurazione della sottorisorsa
 a| 
Ripristina le informazioni.



 a| 
SUSR
 a| 
URN utente S3 (mittente della richiesta)
 a| 
L'ID account tenant e il nome utente dell'utente che effettua la richiesta. L'utente può essere un utente locale o un utente LDAP. Per esempio: `urn:sgws:identity::03393893651506583485:root`

Vuoto per le richieste anonime.



 a| 
TEMPO
 a| 
Tempo
 a| 
Tempo totale di elaborazione della richiesta in microsecondi.



 a| 
TLIP
 a| 
Indirizzo IP del bilanciatore di carico affidabile
 a| 
Se la richiesta è stata instradata da un bilanciatore di carico Layer 7 affidabile, l'indirizzo IP del bilanciatore di carico.



 a| 
UUID
 a| 
Identificatore univoco universale
 a| 
L'identificativo dell'oggetto all'interno del sistema StorageGRID.



 a| 
VSID
 a| 
ID versione
 a| 
L'ID versione della versione specifica di un oggetto che è stata richiesta. Le operazioni sui bucket e sugli oggetti nei bucket senza versione non includono questo campo.

|===
