= Messaggio di audit CBSE per la fine dell'invio dell'oggetto in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando il trasferimento di un blocco di contenuto da un nodo a un altro è completato, questa entità di origine emette questo messaggio.

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CNID
 a| 
Identificatore di connessione
 a| 
L'identificativo univoco della sessione/connessione nodo-nodo.



 a| 
CBID
 a| 
Identificatore del blocco di contenuto
 a| 
L'identificativo univoco del blocco di contenuto in fase di trasferimento.



 a| 
CTDR
 a| 
Direzione di trasferimento
 a| 
Indica se il trasferimento CBID è stato avviato tramite push o pull:

PUSH: L'operazione di trasferimento è stata richiesta dall'entità mittente.

PULL: L'operazione di trasferimento è stata richiesta dall'entità ricevente.



 a| 
CTSR
 a| 
Entità di origine
 a| 
L'ID del nodo sorgente (mittente) del trasferimento CBID.



 a| 
CTDS
 a| 
Entità di destinazione
 a| 
L'ID del nodo di destinazione (ricevente) del trasferimento CBID.



 a| 
CTSS
 a| 
Inizio conteggio sequenza
 a| 
Indica il numero di sequenza da cui è iniziato il trasferimento.



 a| 
CTAS
 a| 
Conteggio effettivo della sequenza finale
 a| 
Indica l'ultimo conteggio di sequenza trasferito correttamente. Se il conteggio effettivo della sequenza finale è uguale al conteggio della sequenza iniziale e il risultato del trasferimento non è stato positivo, non è stato scambiato alcun dato.



 a| 
RSLT
 a| 
Risultato del trasferimento
 a| 
Il risultato dell'operazione di trasferimento (dal punto di vista del soggetto mittente):

SUCS: Trasferimento completato con successo; tutti i conteggi di sequenza richiesti sono stati inviati.

CONL: connessione persa durante il trasferimento

CTMO: connessione scaduta durante la fase di stabilimento o trasferimento

UNRE: ID nodo di destinazione irraggiungibile

CRPT: trasferimento terminato a causa della ricezione di dati corrotti o non validi

|===
Questo messaggio di audit indica che un'operazione di trasferimento dati da nodo a nodo è stata completata. Se il risultato del trasferimento (Transfer Result) è positivo, l'operazione ha trasferito i dati da "Start Sequence Count" a "Actual End Sequence Count". I nodi di invio e ricezione sono identificati dai relativi ID nodo. Queste informazioni possono essere utilizzate per tracciare il flusso di dati del sistema e per individuare, tabulare e analizzare gli errori. Se combinato con i messaggi di audit dello storage, può essere utilizzato anche per verificare il numero di repliche.
