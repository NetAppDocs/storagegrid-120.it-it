= Messaggio di audit OVWR per sovrascritture di oggetti in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Questo messaggio viene generato quando un'operazione esterna (richiesta dal client) provoca la sovrascrittura di un oggetto da parte di un altro oggetto.

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CBID
 a| 
Identificatore del blocco di contenuto (nuovo)
 a| 
Il CBID del nuovo oggetto.



 a| 
CSIZ
 a| 
Dimensione oggetto precedente
 a| 
La dimensione, in byte, dell'oggetto che stai sovrascrivendo.



 a| 
OCBD
 a| 
Identificatore del blocco di contenuto (precedente)
 a| 
Il CBID dell'oggetto precedente.



 a| 
UUID
 a| 
Identificativo univoco universale (nuovo)
 a| 
L'identificativo del nuovo oggetto all'interno del sistema StorageGRID.



 a| 
OUID
 a| 
ID univocamente universale (precedente)
 a| 
L'identificativo dell'oggetto precedente all'interno del sistema StorageGRID.



 a| 
PATH
 a| 
Percorso oggetto S3
 a| 
Il percorso dell'oggetto S3 utilizzato sia per l'oggetto precedente che per quello nuovo



 a| 
RSLT
 a| 
Codice risultato
 a| 
Risultato della transazione di sovrascrittura dell'oggetto. Risultato è sempre:

SUCS: Operazione riuscita



 a| 
SGRP
 a| 
Sito (gruppo)
 a| 
Se presente, l'oggetto sovrascritto è stato eliminato nel sito specificato, che non è il sito in cui l'oggetto sovrascritto è stato inserito.

|===
