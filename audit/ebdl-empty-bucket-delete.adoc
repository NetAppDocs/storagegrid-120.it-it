= Messaggio di audit EBDL per le eliminazioni di oggetti bucket vuoti in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Lo scanner ILM ha eliminato un oggetto in un bucket che sta eliminando tutti gli oggetti (eseguendo un'operazione di svuotamento del bucket).

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
CSIZ
 a| 
Dimensioni dell'oggetto
 a| 
La dimensione dell'oggetto in byte.



 a| 
PATH
 a| 
Bucket/chiave S3
 a| 
Il nome del bucket S3 e il nome della chiave S3.



 a| 
SEGC
 a| 
UUID del container
 a| 
UUID del container per l'oggetto segmentato. Questo valore è disponibile solo se l'oggetto è segmentato.



 a| 
UUID
 a| 
Identificatore univoco universale
 a| 
L'identificativo dell'oggetto all'interno del sistema StorageGRID.



 a| 
RSLT
 a| 
${post_edited_translations.segment}
 a| 
Il risultato di un evento, processo o transazione. Se non è rilevante per un messaggio, viene utilizzato NONE anziché SUCS così il messaggio non viene filtrato accidentalmente.

|===
