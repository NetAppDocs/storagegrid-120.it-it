= Messaggio di audit S3SL per le richieste S3 Select in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Questo messaggio registra un completamento dopo che una richiesta S3 Select è stata restituita al client. Il messaggio S3SL può includere dettagli sul messaggio di errore e sul codice di errore. La richiesta potrebbe non essere andata a buon fine.

[cols="1a,1a,4a"]
|===
| Codice | Campo | Descrizione 


 a| 
BYSC
 a| 
Byte scansionati
 a| 
Numero di byte scansionati (ricevuti) dai nodi di Storage.

BYSC e BYPR potrebbero essere diversi se l'oggetto è compresso. Se l'oggetto è compresso, BYSC avrà il conteggio dei byte compressi e BYPR avrà i byte dopo la decompressione.



 a| 
BYPR
 a| 
Byte elaborati
 a| 
Numero di byte elaborati. Indica quanti byte di "Byte scansionati" sono stati effettivamente elaborati o utilizzati da un job S3 Select.



 a| 
BYRT
 a| 
Byte restituiti
 a| 
Numero di byte che un job S3 Select ha restituito al client.



 a| 
REPR
 a| 
Record elaborati
 a| 
Numero di record o righe che un processo S3 Select ha ricevuto dai nodi di archiviazione.



 a| 
RERT
 a| 
Record restituiti
 a| 
Numero di record o righe che un job S3 Select ha restituito al client.



 a| 
JOFI
 a| 
Lavoro completato
 a| 
Indica se il job S3 Select è terminato o meno. Se questo valore è falso, il job non è riuscito a terminare e i campi di errore probabilmente conterranno dei dati. Il client potrebbe aver ricevuto risultati parziali o nessun risultato.



 a| 
REID
 a| 
ID richiesta
 a| 
Identificativo per la richiesta S3 Select.



 a| 
EXTM
 a| 
Tempo di esecuzione
 a| 
Il tempo, in secondi, impiegato dal processo S3 Select per completare.



 a| 
ERMG
 a| 
Messaggio di errore
 a| 
Messaggio di errore generato dal job S3 Select.



 a| 
ERTY
 a| 
Tipo di errore
 a| 
Tipo di errore che il processo S3 Select ha generato.



 a| 
ERST
 a| 
Stack trace dell'errore
 a| 
Stacktrace dell'errore generato dal job S3 Select.



 a| 
S3BK
 a| 
Bucket S3
 a| 
Il nome del bucket S3.



 a| 
S3AK
 a| 
ID della chiave di accesso S3 (mittente della richiesta)
 a| 
L'ID della chiave di accesso S3 per l'utente che ha inviato la richiesta.



 a| 
S3AI
 a| 
ID account tenant S3 (mittente della richiesta)
 a| 
L'ID account tenant dell'utente che ha inviato la richiesta.



 a| 
S3KY
 a| 
Chiave S3
 a| 
Il nome della chiave S3, escluso il nome del bucket.

|===
