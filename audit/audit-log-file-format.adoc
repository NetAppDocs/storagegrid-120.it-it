= Scopri il formato dei file di log di audit in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
I file di log di audit si trovano su ogni Admin Node e contengono una raccolta di singoli messaggi di audit.

Ogni messaggio di audit contiene quanto segue:

* ${post_edited_translations.segment}
+
`_YYYY-MM-DDTHH:MM:SS.UUUUUU_`, dove  `_UUUUUU_` sono microsecondi.

* Il messaggio di audit stesso, racchiuso tra parentesi quadre e che inizia con `AUDT`.

Nel loro formato predefinito, i messaggi di audit nei file di log di audit non sono facili da leggere o interpretare. Puoi usare link:using-audit-explain-tool.html["strumento audit-explain"] per ottenere riepiloghi semplificati dei messaggi di audit nel file di log di audit. Puoi usare link:using-audit-sum-tool.html["strumento audit-sum"] per riepilogare quante operazioni di scrittura, lettura ed eliminazione sono state registrate e quanto tempo hanno impiegato queste operazioni.
